## 🌟 Overview

**WorkBridge** is a scalable, production-ready **HR Management System (HRMS)** designed and developed by **Md Aftab Alam** to automate and optimize HR workflows.

🔥 Built with real-world architecture using **Spring Boot + React + MySQL**

### ✨ Core Features

* Employee Management
* Payroll Automation
* Attendance & Leave Workflow
* Recruitment & Onboarding
* Performance Tracking
* HR Analytics Dashboard

---

## ⚡ Tech Stack

### 🎨 Frontend

* React (Vite)
* Tailwind CSS
* Axios
* React Router

### 🛠 Backend

* Spring Boot
* Spring Data JPA
* MySQL
* REST APIs
* JWT Authentication (optional)

## ⚙️ Installation & Setup

### 🟦 Frontend

```bash

npm install
npm run dev
```

### 🟩 Backend

```bash
cd backend
mvn clean install
mvn spring-boot:run
```
